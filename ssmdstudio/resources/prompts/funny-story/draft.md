# Task: write the plain-language story draft

Write the complete funny story as spoken prose, but **do not add SSMD markup yet**.

Use the stored project, characters, and scenes as the source of truth. Do not silently replace
them with a different premise. Preserve locked scenes and explicit constraints.

Write for the ear:

- make place, action, consequences, and transitions understandable without visual context;
- keep recurring character identities stable;
- use narration for physical action, time changes, and consequences;
- let comic rhythm come first from wording, sentence length, timing, escalation, and callbacks;
- after long dialogue runs, add a concise action beat when the listener would otherwise have
  to infer too much;
- do not over-explain the ending;
- if duration is specified, target roughly 120–150 spoken words per minute before accounting
  for comic pauses.

Return only the story draft in natural prose. Do not include analysis, YAML, SSMD directives,
or Markdown fences.
