# Starter SSMD template provenance

These editable starter documents were copied from the Readio project, commit
`ee5f3c51ca943930d6d5e406e8b6244b209cbf7e`, from:

- `readio/resources/templates/briefing.ssmd`
- `readio/resources/templates/dialogue.ssmd`
- `readio/resources/templates/podcast.ssmd`

They are SSMD documents, not prompts. Their symbolic voice roles are intentionally
provider-neutral. SSMDStudio owns these first-party copies and packages them as
resources; later changes should be made here rather than loaded from Readio.
